# Mono sync — 2026-07-16

Forward-port of the ADR-0010 **updateResult** tracing delta from `nightheron-mono`
(`main` @ `25aca01`, PR #80) and the extracted framework repo `nightheron-state-machine`
(@ `c9d3fb7`, PR #1). Previous sync: [2026-07-08](mono-sync-2026-07-08.md) (`3e457fc`),
which froze this repo at mono's 2026-07-03/05 state.

Scope: Update-handler return values are now persisted in the transition projection and
surfaced in the order-trace dev tool — the driver computes the update response before
recording, the sink serializes/size-caps it, the `workflow_state_transitions` table gains an
`update_result` column, and `/dev/order-trace` renders it on both timelines.

## Schema note for existing local stacks

`workflow_state_transitions` is created with `CREATE TABLE IF NOT EXISTS`, so an already-
initialized stack will not pick up the new column. `npm run dev:init` (full wipe) is the
canonical path. To keep a live stack instead:

```cql
ALTER TABLE catalog.workflow_state_transitions ADD update_result TEXT;
```
